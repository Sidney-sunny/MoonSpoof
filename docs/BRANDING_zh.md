# MoonSpoof 品牌

[English](BRANDING.md)

正式标志是 `docs/assets/logo.png` 中的 MS 雕刻字形与 MoonSpoof 字标。月相负形及不同的轮廓对应 Unicode 近似字形。配套 README 横幅为 `docs/assets/banner.png`。两张图片均使用内置生图工具生成，遵循负责人更换风格、避开朱红撞色方案的要求。

品牌方向为深葡萄紫 `#49304F` 与珍珠白 `#F4F2F6`，横幅辅以浅丁香色 `#E4DEE9`。这些是生图配色参考，不代表每个栅格像素都是统一的色值。Logo 保留透明通道，准确生成提示词写入 PNG 元数据。

网站将 Logo 复制至 `playground/public/logo.png`，用于页眉、页脚和网站图标。页眉和页脚图片使用珍珠白 CSS 底色，使深紫图案在深色界面上清晰可辨。不拉伸、不改色、不另绘替代标志。旧素材可从 Git 历史恢复。

负责人要求换色，因为之前的琥珀配色与另一个项目相同。当前哑光配色为墨蓝 `#0e1824`、表面 `#152333`、冷白 `#eef5fa`、次要蓝 `#b0c4d5`、冰青 `#78dce8` 与结构线 `#526a80`。冰青标记操作、选中字形和发现。错误文字为 `#ffb7c3`；状态同时提供文字或选中标志。不使用霓虹发光、渐变和装饰卡片。

演示采用字形鉴定台：大型双字形、可编辑比较、直接结论、可选码点证据、有来源的竞品矩阵及实现边界。React 管理界面，工作线程执行 MoonBit 的 JavaScript 目标，支持中英文。详细令牌、断点、焦点和动效规则见 [DESIGN.md](../DESIGN.md)。
