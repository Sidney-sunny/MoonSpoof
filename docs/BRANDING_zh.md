# MoonSpoof 品牌形象与视觉规范

本文档阐述 MoonSpoof 的品牌理念、色彩设计标记（Design Tokens）与官方视觉资产使用规范。

---

## 1. 品牌理念与图形寓意

MoonSpoof 的品牌图形将月相精密度与字符安全相结合：
- **纯白月牙**：代表 MoonBit 原生生态的高性能与清晰度。
- **双联字符环 (Twin Loop)**：象征 Unicode 同形异义字（Homoglyphs）在安全透镜下的捕捉与等价解析。
- **极简单色主义**：纯正黑白极简风格，严禁蓝、绿、紫赛博朋克与霓虹灯光效。

---

## 2. 调色板与设计标记 (Tokens)

| 标记名称 | 十六进制色彩 | 语义应用场景 |
| :--- | :--- | :--- |
| **黑曜纯黑 (Obsidian)** | `#0d0d0d` | 主背景色、控制台画布底色 |
| **月芒纯白 (Moon White)** | `#ffffff` | 核心品牌标识徽章、主标题 |
| **中性板岩 (Slate)** | `#71717a` | 副标题、注释信息、辅助结构线 |
| **暗灰边框 (Border)** | `#27272a` | 分割线、表格与卡片描边 |
