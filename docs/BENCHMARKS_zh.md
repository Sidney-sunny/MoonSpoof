# MoonSpoof 性能与吞吐量基准测试报告

本报告记录了 MoonSpoof 在 Unicode 16.0.0 与 UTS #39 数据集下的实际性能指标、吞吐量以及算法扩展性评估。

---

## 1. 测试环境配置

| 参数 | 配置说明 |
| :--- | :--- |
| **编译器** | MoonBit `0.1.20260904` |
| **目标运行时** | JavaScript / WebAssembly 核心 (Node.js v22 LTS) |
| **Unicode 版本** | Unicode 16.0.0 |
| **UTS #39 表规模** | 6,355 条混淆映射项，929 条脚本边界区间 |
| **操作系统** | Windows 11 x64 |

---

## 2. 基准测试实测数据

### 2.1 单对标识符等价性比对 (`are_confusable`)

测试在 50,000 次迭代下，包含完整 UTS #39 Skeleton 骨架变换、全角 ASCII 预分解以及二分查找映射的延迟与吞吐能力。

| 指标 | 实测数值 |
| :--- | :--- |
| **测试样本量** | 50,000 次比对 |
| **总耗时** | 262.46 ms |
| **平均延迟** | 5.25 微秒 / 次 |
| **吞吐量** | 190,507 次 / 秒 |

### 2.2 高吞吐量批量碰撞聚类分析 (`find_confusable_groups`)

测试在 1,000 与 10,000 规模的大规模标识符集合下（包含拉丁、西里尔同形字及零宽不可见字符混合攻击样本）的聚类性能。

| 数据集规模 | 总耗时 | 处理速率 | 检出碰撞聚类数 |
| :--- | :--- | :--- | :--- |
| **1,000 标识符** | 6.69 ms | 149,392 标识符 / 秒 | 50 个聚类 |
| **10,000 标识符** | 16.85 ms | 593,356 标识符 / 秒 | 200 个聚类 |

---

## 3. 算法复杂度分析

- **骨架变换 (Skeleton Transformation)**：$O(L \log M)$，其中 $L$ 为标识符字符长度，$M = 6,355$ 为静态 UTS #39 表规模（基于静态二分查找）。
- **批量碰撞分组 (Batch Collision Grouping)**：$O(N \cdot L \log M)$，其中 $N$ 为总标识符数量，依托单趟哈希索引桶（均摊 $O(1)$ 查找插入）。
- **脚本解析 (Script Analysis)**：$O(L \log S)$，其中 $S = 929$ 为脚本边界区间总数。
