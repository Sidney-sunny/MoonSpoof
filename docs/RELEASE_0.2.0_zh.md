# MoonSpoof 0.2.0 发布说明

[English](RELEASE_0.2.0.md)

发布于 2026-10-30。工具链：`moonc 0.10.18+6c83a7f62`。数据：Unicode 16.0.0，固定校验值的九份官方文件。Mooncakes 与 GitHub 发布验证见[验收报告](ACCEPTANCE_zh.md)。

## 本版交付

完整 Script/Script_Extensions 查询与解析字系集合；提供类型化失败的可选原始 Identifier_Status 过滤；覆盖 76 个 Nd 系统的十进制混用检查；包含明确决策、版本化快照与受控重建的可运行注册接入；可复现的 ICU4J 76.1 对照，并固定所有已观察差异。证据与边界见[机制覆盖矩阵](REFERENCE_COMPARISON_zh.md)。

这些机制相对 GitHub `v0.1.0` tag 属于新增。单独发布的 Mooncakes `0.1.0` 已包含后续许多字系/状态/数字 API 与接入测试。相对注册表旧包，0.2.0 主要交付固定的 0.10.18 工具链、完整分发声明、发布验证与测量，以及明确的库版本身份。不能将两份 0.1.0 产物视为同一基线。

新增 `get_library_version() -> String`，返回 `"0.2.0"`。注册元数据直接读取该 API，不再重复硬编码版本号；CI 同步核验公开门面、模块和演示版本。新增两项公开回归后 MoonBit 共 99 项测试，包括 0.1.0 到 0.2.0 的索引迁移。

## 兼容性与迁移

| 范围 | 契约 |
| --- | --- |
| 编译器 | 使用精确固定的 0.10.18 并重新编译调用方；不声明支持旧编译器 |
| 既有公开 API | 保留可见性和可省略的 profile 参数；生成接口中的 `Int32` 是编译器对同一 32 位整数类型的别名拼写 |
| 键与 Unicode | Unicode 版本、骨架算法/数据、敏感/折叠等价策略和默认配置保持不变 |
| 参考索引存储 | 版本元数据升为 0.2.0；直接恢复 0.1.0 元数据会失败，需从原始名称重建，成功后再切换 |
| 可选过滤 | 启用 Identifier_Status 或数字混用时需新应用策略版本并复核新增拒绝，两者都不会自动成为默认配置 |

运行 `moon run cmd/registration`。[迁移回归](../examples/registration/snapshot_test.mbt)验证旧元数据重建后键不变，旧快照得到保留。应用仍负责并发写入协调及数据库原子约束；参考存储没有数据库或序列化快照适配器。

## 验证与分发

发布要求 CI 中 WASM、JavaScript、native 检查/构建/测试通过，另有 19 项生成器测试、浏览器 ABI/Worker 检查、4,456,448 项全码点属性断言、官方 NFD/映射验证与 42 组 ICU 语料。[性能报告](BENCHMARKS_zh.md)公开输入、运行时、编译器、硬件、多轮原始样本及复现命令，不做竞品排名。

发行归档来自干净的已提交源码，包含源码/引擎/站点、许可证全文、发布清单及 SHA-256 校验值。引擎和站点构建元数据必须匹配发布提交、编译器及版本。原创源码采用 Apache-2.0；Unicode、Manrope、React、Vite 保留[各自上游声明](THIRD_PARTY_NOTICES_zh.md)。

源码 ZIP 在没有 `.git` 时仍可利用归档元数据构建；这种未纳入版本控制的构建会标记为 dirty，不能重新打包为经过验证的干净发行输入。

## 限制

不声明完整 UTS #39 合规、原始状态过滤的规范等价闭包、双向骨架重排、NFKC/NFKD、IDNA 或地区相关大小写。旧限制等级估计仍有范围限制。接入属于仓库参考实现，不是外部生产采用证据。
