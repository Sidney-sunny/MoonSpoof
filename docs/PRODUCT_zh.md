# MoonSpoof 产品定义

[English](../PRODUCT.md)

## 用户与目的

目标用户是在账号或包名中检查混淆碰撞的 MoonBit 开发者。评审通过演示站查看正确性与接入潜力。目前尚未记录真实应用采用。

在标识符注册与批量复核的调用位置提供可复用的 Unicode 混淆键和诊断证据。下一项交付是可运行的账号注册参考接入；演示站用于查看底层机制。

## 产品定位

无运行时第三方依赖的 MoonBit 引擎，使用 Unicode 16.0 生成数据，提供混淆骨架、字符诊断、可配置标识符策略与哈希分组。浏览器使用编译后的 JavaScript，WASM 与 native 是独立的库目标。

## 使用场景

计划中的注册接入通过公开库 API 加载已有标识符、检查候选名称，区分完全重复、混淆碰撞和策略不通过。语法规则和碰撞策略由应用选择。开发者可在演示站查看双字符串与批量结果，输入不会上传。

## 开发优先级

根据负责人反馈，项目已通过初审。[路线图](ROADMAP_zh.md)定义尚未完成的里程碑及验收条件：注册接入、字系与标识符状态支持、数字混用与参考对照，最后复核接入并发布。通过初审不代表终审通过或达到生产可用状态。

## 约束

尽量保持公开 API。诊断是风险信号，不证明恶意。没有实现与一致性证据时不得声明完整 UTS #39 合规。浏览器不上传输入。负责人已授权架构与实现重构。

## 已有证据

源代码、测试、数据生成器、Apache-2.0 许可及技术文档。竞品对比采用官方 API 资料；不存在受控竞品性能测试，也尚未记录真实应用采用。不得虚构速度排名，或将计划中的参考接入描述为外部采用。

## 品牌约束

保留 MoonSpoof 名称。负责人要求更换品牌，并拒绝了与其他项目撞色的朱红方案；新品牌使用 docs/assets/logo.png 的 MS 雕刻字形与 docs/assets/banner.png 的配套横幅，采用深葡萄紫与珍珠白方向。网站完整支持中英文，界面保留哑光墨蓝与冰青配色。不制作装饰提示标签或虚构性能排名。
