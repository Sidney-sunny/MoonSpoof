# MoonSpoof 数据生成器

用于下载并预处理官方 Unicode 16.0.0 与 UTS #39 规范数据，生成 MoonBit 静态查找表。

## 规范数据源

- `https://www.unicode.org/Public/security/16.0.0/confusables.txt`
- `https://www.unicode.org/Public/16.0.0/ucd/Scripts.txt`
- `https://www.unicode.org/Public/16.0.0/ucd/ScriptExtensions.txt`

## 运行方式

```powershell
python generate.py
```
