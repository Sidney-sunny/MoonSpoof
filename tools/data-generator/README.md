# MoonSpoof Data Generator

Scripts for fetching and preprocessing official Unicode 16.0.0 and UTS #39 datasets into MoonBit static lookup tables.

## Data Sources

- `https://www.unicode.org/Public/security/16.0.0/confusables.txt`
- `https://www.unicode.org/Public/16.0.0/ucd/Scripts.txt`
- `https://www.unicode.org/Public/16.0.0/ucd/ScriptExtensions.txt`

## Execution

```powershell
python generate.py
```
